TRAILS · checkpoint / gating mode

Agent paused — your approval needed

In gating mode the agent runs live but stops before any risky action. The human reviews the action in context, then approves, edits, or rejects it — and every decision is recorded as an oversight trail (EU AI Act, Art. 14).
