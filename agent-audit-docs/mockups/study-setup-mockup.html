2 Trajectory source

Import a benchmark run planned

3 Control mode

Where the human sits in the loop. This drives the whole review UX.

Post-hoc replay supported
Agent runs to completion; the frozen trajectory is reviewed afterward. Most scalable and comparable.
Checkpoint / gating preview · page 3
Agent pauses at risky actions; the human approves, edits, or rejects before it proceeds.
Live monitor planned
Agent runs autonomously; the human watches and can flag or interrupt.
